# WiiFitToVRC

**日本語** | [English](README.en.md) | [한국어](README.ko.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md)

Wiiバランスボードを、VRChat(またはその他のWindowsアプリ)向けの歩行コントローラーに変えるアプリです。ボードに乗って体重を移動させるだけで、前進・後進・旋回・ジャンプ・しゃがみをキーボード/マウス入力、仮想Xboxコントローラー入力、またはVRChatのOSC入力に変換します。

## かんたん導入(はじめての方へ)

プログラミングの知識は一切不要です。以下の手順だけで動作します。

1. WindowsのBluetoothをオンにする(Bluetoothアンテナが無い場合はUSBドングルなどを別途ご用意ください)。
2. このリポジトリのトップページにある `WiiFitToVRC.exe` をクリックしてダウンロードします(インストール作業は不要です)。
3. ダウンロードしたファイルをダブルクリックして起動します。
4. アプリは起動した時点で自動的に検索を始めます。Wiiバランスボードの電池ボックスにある **SYNC** ボタンを押すだけで、自動的に接続されます(POWERボタンは仕様上利用できないので、SYNCボタンを接続のたびに毎回押す必要があります）
5. 接続が完了すると、キャリブレーションも自動的に始まります。「機器を床に置いてください」と表示されてから5秒後に自動で開始されるので、それまでにボードを床に置いて何も乗せない状態にしてください。
6. キャリブレーション完了後、ボードに乗ってしばらく普通に立っていれば準備完了です。あとはVRChatを起動し、ボードの上で体重を移動すれば歩けます。

補足: メモ帳を開いた状態でボードを踏み、w/s/a/dが出力されれば接続は正常です。それでもVRモードなどでゲームが反応しない場合は、VRC側のOSC機能をオンにしたうえで、設定の出力方式を「OSC機能(VRC専用)」に切り替えて試してください。

うまく動かないときは、各機能の詳しい説明([docs](docs/)フォルダ、英語)を参照してください。

## できること

- 歩行
- ダッシュ
- 左右旋回
- ジャンプ
- しゃがみ

## 動作環境

- Windows 10/11
- Wiiバランスボード(Bluetooth) — 生産終了製品ですが、中古市場で安価に入手できます
- HIDデバイスに対応したBluetoothアダプター

### 仮想コントローラーを使用する場合(任意)

[ViGEmBus](https://github.com/nefarius/ViGEmBus/releases)(実在のカーネルドライバです — このアプリから自動インストールすることはできないため、ご自身でダウンロード・インストールしてください)

## 注意

ジャンプをする動作はWiiバランスボード本来の仕様では非対応となっていますので、
器具や床の破損など、身の回りに気をつけたうえ、**体重100kg以上の方はおこなわないようにしてください**。
軽いジャンプでも反応します。

## VRChat以外のゲームでも使えます

本アプリの出力は通常のキーボードWASD(またはマウス)入力なので、公式にサポートされているわけではなくても、WASD入力に対応してさえいれば歩行が中心の他のゲームでも動作します。試している例:

- Death Stranding
- Resident Evil
- Monster Hunter
- Armored Core IV

## 特徴

- **PIN入力なしでBluetoothペアリング** — 仕組みは[docs/BALANCE_BOARD.md](docs/BALANCE_BOARD.md)(英語)を参照。
- **2段階のキャリブレーション**: センサーのゼロ点を合わせる一回限りのキャリブレーション(ボードから降りて実施)と、常時バックグラウンドで自動更新され続ける「基準体重」(別の人が乗ってもすぐに追従します)。
- **前進・後進・ダッシュ・左右旋回・ジャンプ・しゃがみのジェスチャー検知** — それぞれの判定ロジックと調整可能な設定項目は[docs/GESTURE_DETECTION.md](docs/GESTURE_DETECTION.md)(英語)を参照。
- **4つの出力モード**:
  - キーボード(旋回はQ/Eキー)
  - キーボード+マウス(旋回はマウスの視点移動 — デフォルト)
  - VRChatのOSC機能を利用 — VR機器に入力がロックされ、仮想コントローラーを含むあらゆる合成入力を受け付けない環境向け。詳細は[docs/VRCHAT_INPUT.md](docs/VRCHAT_INPUT.md)(英語)を参照。
  - 仮想コントローラー — SendInputによる合成キーボード/マウス入力を拒否するゲーム(VRChatを含む)向け。詳細は[docs/VRCHAT_INPUT.md](docs/VRCHAT_INPUT.md)(英語)を参照。
- キーバインド/コントローラー割り当て、旋回感度、荷重しきい値、各種タイミングなど、アプリ内の設定画面から細かく調整可能。
- 多言語UI: Windowsの表示言語を自動検出。日本語・英語・簡体字/繁体字中国語・韓国語・フランス語・ドイツ語・イタリア語に対応。

## ソースからのビルド

[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)が必要です。

```
dotnet build WiiFitToVRC.sln
```

リポジトリのルートに配置されている自己完結型の単一exeを生成するには:

```
powershell -File publish.ps1
```

## 設定リファレンス

すべての設定はアプリ内の設定画面(⚙ 設定)から編集でき、exeと同じフォルダの`settings.json`に保存されます。手動編集の必要はありませんが、概要は以下の通りです:

| 設定項目 | 内容 |
|---|---|
| 出力方式 | キーボード / キーボード+マウス / VRChat OSC / 仮想コントローラー(詳細は[docs/VRCHAT_INPUT.md](docs/VRCHAT_INPUT.md)) |
| 言語 | UIの表示言語。自動でWindowsの設定に追従も可能 |
| 反応のしやすさ(歩き/ダッシュ/旋回/ジャンプ/しゃがみ/歩幅/歩行・ダッシュの継続判定) | それぞれ独立に「弱い」〜「強い」(歩幅・歩行/ダッシュの継続判定は「狭い」〜「広い」)のスライダーで調整可能(前進/後進には影響しません)。既定値(中央)は従来の判定基準のまま。歩き・歩幅・歩行/ダッシュの継続判定を除く4項目は「弱い」を最小(0)にすると、判定に関係なく一切キー出力されなくなります — 詳細は[docs/GESTURE_DETECTION.md](docs/GESTURE_DETECTION.md) |
| 旋回方式 | 旋回の判定ロジックを「長押し」(左右への傾きを一定時間保持)と「足踏み」(対角パネルの交互踏み、既定)から選択可能 |
| ダッシュの入力方式 | キーボード/キーボード+マウスモードでのダッシュ送信方法を「複合キー」(修飾キー+前進キー、既定)と「キー2度押し」(前進キーを1度押したあと長押し)から選択可能 |
| 旋回感度 | マウスの移動量(キーボード+マウスモード)またはスティック偏移%(コントローラーモード)。左右別々に設定可能 |
| 反応する荷重のしきい値 | 「ボードに人が乗っている」と判定する較正後の合計荷重 |
| スリープ・復帰までの秒数 | 出力がロック/解除されるまでに必要な継続時間(両方向共通) |
| 旋回動作の有効化 | オフにすると旋回自体を検知しなくなり、マウス・キーボード・コントローラー・OSCいずれの出力モードでも左右旋回に相当する動きが一切送信されません(前進/後進/ダッシュには影響しません) |
| デバッグモード | `ClassifyTest`用のログを記録する生データ記録コントロールを表示 |
| キー割り当てタブ | キーボード出力モード時の各アクションのキー(ダッシュの修飾キーを含む) |
| コントローラータブ | 仮想コントローラーモード時の各アクションのボタンとスティック偏移量 |
